# Linux Administration Documentation

This section contains technical documentation for the Linux Server Administration Lab.

It describes the lab environment, Linux administration tasks, troubleshooting procedures, and Bash automation.

## Documentation Structure

### Lab Environment
- [Lab Environment](lab-environment.md) — overview of the laboratory infrastructure and tools.

### Linux Administration
- Users and Groups — user account and group management.
- File Permissions — Linux ownership and access permissions.
- Processes and Services — process management and systemd.
- Disks and Filesystems — storage and filesystem administration.
- Networking — network configuration and troubleshooting.
- System Logs — system log analysis and troubleshooting.

### Bash Automation
- System Information Script — documentation for the system information collection script.

## Project Approach

All documentation is based on practical exercises performed in the laboratory.

Commands, configuration examples, and troubleshooting procedures are documented as they are tested and verified.

The documentation is maintained in Markdown and version-controlled with Git.
