# Linux Filesystem Administration

## 1. Linux Filesystem Hierarchy

### 1.1. Filesystem Hierarchy Standard (FHS)

Linux использует единую иерархическую структуру файловой системы.

Корневой каталог `/` является начальной точкой всей файловой иерархии. Все остальные каталоги и файлы располагаются внутри него.

Filesystem Hierarchy Standard (FHS) определяет назначение основных каталогов Linux.

### 1.2. Основные каталоги

| Каталог | Назначение |
|---|---|
| `/` | Корень файловой системы |
| `/bin` | Основные пользовательские команды |
| `/boot` | Файлы загрузчика и ядра |
| `/dev` | Файлы устройств |
| `/etc` | Системные конфигурационные файлы |
| `/home` | Домашние каталоги обычных пользователей |
| `/lib` | Основные системные библиотеки |
| `/media` | Точки монтирования съёмных носителей |
| `/mnt` | Временные точки монтирования |
| `/opt` | Дополнительное программное обеспечение |
| `/proc` | Виртуальная файловая система с информацией о процессах и ядре |
| `/root` | Домашний каталог пользователя root |
| `/run` | Данные времени выполнения системы |
| `/sbin` | Системные административные команды |
| `/srv` | Данные, предоставляемые системными службами |
| `/sys` | Интерфейс к устройствам и подсистемам ядра |
| `/tmp` | Временные файлы |
| `/usr` | Пользовательские программы, библиотеки и документация |
| `/var` | Изменяемые данные: журналы, кэш, очереди и другие данные служб |

**Примечание:** в современных Ubuntu используется механизм UsrMerge.

Традиционные каталоги `/bin`, `/sbin` и `/lib` представлены символическими ссылками на соответствующие каталоги внутри `/usr`.

### 1.3. Каталоги, важные для DevOps

- `/etc` — конфигурация служб и системных компонентов.
- `/var/log` — системные журналы и логи приложений.
- `/var/www` — распространённое расположение файлов веб-сайтов; это соглашение, а не обязательное требование FHS.
- `/home` — домашние каталоги пользователей.
- `/root` — домашний каталог суперпользователя.
- `/usr/bin` — исполняемые программы.
- `/tmp` — временные файлы.
- `/opt` — дополнительное программное обеспечение.

### 1.4. Практическое исследование корневого каталога

Для просмотра содержимого корневого каталога используется:

```bash
ls -la /
```

В лабораторной среде Ubuntu Server 24.04.4 LTS команда показала основные каталоги файловой системы, включая `/etc`, `/home`, `/usr`, `/var`, `/proc` и `/sys`.

Также обнаружены:

- `swap.img` — файл подкачки.
- `lost+found` — служебный каталог файловой системы.
- `cdrom` — каталог, связанный с точкой монтирования CD-ROM.

### 1.5. Символические ссылки и UsrMerge

В Ubuntu Server 24.04.4 LTS обнаружены следующие символические ссылки:

```text
/bin  -> /usr/bin
/lib  -> /usr/lib
/lib64 -> /usr/lib64
/sbin -> /usr/sbin
```

Это часть механизма UsrMerge, объединяющего традиционные каталоги `/bin`, `/sbin` и `/lib` с соответствующими каталогами внутри `/usr`.
Наличие и назначение `/lib64` зависят от архитектуры системы и её конфигурации.
Проверить ссылки можно командой:

```bash
ls -ld /bin /sbin /lib /lib64
```

В выводе символическая ссылка обозначается буквой `l` в начале строки, а её целевой путь отображается после `->`.

### 1.6. Практические команды

| Команда | Назначение |
|---|---|
| `ls -la /` | Просмотр корневого каталога |
| `ls -ld /bin /sbin /lib` | Просмотр информации о каталогах и ссылках |
| `pwd` | Вывод текущего рабочего каталога |
| `whoami` | Вывод имени текущего пользователя |

**Примечание:** практические наблюдения в этом разделе получены на Ubuntu Server 24.04.4 LTS в лабораторной виртуальной машине.
