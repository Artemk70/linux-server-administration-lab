# Linux Server Administration Lab

## About

This project documents my practical Linux system administration
training using Ubuntu Server and Linux Mint.

The goal is to develop practical skills in Linux administration,
network troubleshooting, system monitoring, and Bash automation.

## Environment

- Ubuntu Server
- Linux Mint
- Bash
- Git
- SSH and SCP
- VirtualBox

## Topics

- Linux filesystem and disk management
- Users, groups, and file permissions
- Processes and systemd services
- Networking and troubleshooting
- System logs and monitoring
- Bash scripting
- SSH and secure file transfer
